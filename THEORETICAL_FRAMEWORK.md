# Formal Research Framework

## 1. Classical Context

Known:

τ(n) ≤ 2√n
Average order: log n
Maximal order: exp((log 2 + o(1)) * log n / log log n)

This project does NOT aim to reprove classical results.

---

## 2. Fluctuation Model

Define:

Δ(n) = τ(n) − log n

Hypothesis H1:
Δ(n) may exhibit multiplicative spectral regularities.

Testable via:

Discrete Fourier Transform (DFT)
Autocorrelation decay analysis
Dirichlet generating function structure

---

## 3. Extremal Geometry

Define:

M(N) = max τ(n), n ≤ N

Investigate:

lim sup structure
gap distribution between extremal indices
density of highly composite numbers

---

## 4. Multidimensional Extension

Define:

τ_k(n) = sum over factorizations into k factors

Research directions:

- Asymptotic scaling for fixed k
- Behavior as k → ∞
- Entropy interpretation of multiplicative partitions

---

All conjectures require:
1. Analytical justification
2. Numerical support
3. Independent reproducibility
