# Explicit Falsifiability Conditions

The claim fails if ANY of the following occurs:

1. |μ_boot − 1/2| > 3σ_boot
2. Adversarial perturbation shifts α beyond statistical boundary.
3. Different deterministic seeds systematically produce α far from 1/2.
4. Increasing sample size n causes drift away from 1/2.
5. Independent reimplementation fails to reproduce results.

If any of these occur, the theorem is rejected.

No reinterpretation.
No symbolic rescue.
Failure is accepted as data.
