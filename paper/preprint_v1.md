# Spectral Stability Under Deterministic Seeds

---

## Abstract

This study presents a reproducible computational framework for
examining spectral structure under deterministic seed control.

The framework separates descriptive measurements, diagnostic
statistical tests, stochastic-null inference, adversarial controls,
and computational reproducibility. No scientific claim is promoted
from a single spectral measurement or from a diagnostic-only test.

The current canonical validation state remains under investigation.
The primary real-data analysis uses Welch power spectral density
estimation, with an FFT-periodogram as an independent numerical
validator. The current canonical primary estimate is alpha = 2.525347.

The declared primary stochastic null is a stationary Gaussian AR(p)
surrogate family with AIC order selection over p = 1..20 and an
upper-tail test of whether the observed canonical spectral exponent
exceeds the corresponding null distribution.

In the current canonical run, 999 of 1000 valid null surrogates
produce an exponent at least as large as the observed value,
yielding the Monte Carlo add-one p-value 0.999001. The primary
stochastic null is therefore not rejected.

The current result does not establish the proposed spectral
persistence hypothesis. Diagnostic permutation-null separation,
scale stability, perturbation stability, and computational
reproducibility are not treated as substitutes for rejection of
the declared primary stochastic null or for independent
real-domain replication.

---

## Research Question

The research question is whether a spectral persistence signature
can remain distinguishable from an appropriately specified
stochastic null model under a declared and reproducible validation
protocol.

The study does not assume that such a signature exists.

---

## Statistical Hypothesis

For the current primary protocol, the endpoint is the canonical
Welch spectral exponent.

The primary null is:

H0: The canonical primary spectral exponent is not greater than
the distribution generated by the declared stationary Gaussian
AR(p) surrogate procedure.

The primary alternative is:

H1: The canonical primary spectral exponent is greater than the
distribution generated by the declared stationary Gaussian AR(p)
surrogate procedure.

The current protocol uses an upper-tail test.

A lower-than-null observation is not counted as support for H1.

---

## Primary Measurement

The primary estimator is Welch power spectral density estimation
with the declared protocol:

- nperseg = 1024
- Hann window
- linear detrending
- density scaling
- 50% overlap
- one-sided spectrum
- canonical frequency band = 0.01-0.05

The independent numerical validation method is an FFT periodogram.

The current canonical values are:

- Welch alpha = 2.525347
- FFT alpha = 2.423397
- absolute difference = 0.101950

This agreement is a measurement-consistency result, not independent
scientific replication.

---

## Primary Stochastic Null

The current exploratory null protocol uses stationary Gaussian AR(p)
surrogates.

The order is selected by AIC over p = 1..20 and refitted for each
surrogate.

Current canonical results:

- valid surrogates = 1000
- null mean = 3.197386
- null standard deviation = 0.235076
- observed alpha = 2.525347
- exceedances = 999
- Monte Carlo p-value = 0.999001
- rejection at alpha = 0.05: false

The primary null is therefore not rejected.

Furthermore, 96.5% of surrogate order selections reach the declared
maximum order of 20. This is treated as a model-capacity diagnostic
requiring further calibration rather than as evidence for or against
the scientific hypothesis.

---

## Diagnostic Results

Several secondary procedures are retained as diagnostics.

The permutation-null test reports p = 0.0002, but it is not the
primary stochastic null and has no claim-promotion authority.

The current multi-scale diagnostic satisfies its declared numerical
spread thresholds, but scale stability alone is not evidence for
the scientific claim.

The current predictive validation does not achieve structural
agreement between training and test regimes.

Perturbation stability demonstrates stability under the declared
seeded perturbations. It does not constitute independent scientific
replication.

---

## Independent Domain Replication

The project requires at least two independent real secondary domains.

Measurement validity alone is not defined as scientific replication.

For scientific replication, each secondary domain must use the same:

- endpoint
- null family
- direction
- tail
- inferential rule

and must independently reject the same primary stochastic null.

The current system has not established that condition.

---

## Reproducibility

Clean-checkout replay is defined as computational reproducibility.

It does not constitute:

- scientific replication
- independent implementation replication
- laboratory replication

These concepts remain explicitly separated.

---

## Epistemic Boundary

The current evidence does not establish:

- HCM causation
- consciousness
- a physical field
- universality
- novel physics
- market advantage
- predictive superiority

Those propositions require separate empirical evidence.

---

## Current Scientific Status

UNDER INVESTIGATION

The correct next step is not to alter the statistical direction,
relax thresholds, or promote diagnostic results.

The next step is to perform a predeclared calibration study of the
primary stochastic-null family, establish estimator behavior over
the relevant spectral range, and then conduct a fresh prospective
validation under a fixed protocol.

---

## Conclusion

The present study demonstrates a reproducible measurement and
validation framework, but the current canonical data do not reject
the declared primary stochastic null.

Accordingly, no discovery claim is made.

The framework remains useful as an explicitly falsifiable system:
future data may strengthen the hypothesis, weaken it, or falsify it.
The protocol is designed to preserve that distinction.
