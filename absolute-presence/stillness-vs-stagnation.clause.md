# Stillness vs Stagnation

Stillness is not inaction.
Stillness is non-reactivity.

Stagnation is decay.
Stagnation is avoidance.

This system does not build from pressure.
But it does repair from fracture.

Allowed:
- Critical bug fixes
- Broken user paths
- Missing documentation that blocks comprehension
- Structural coherence reinforcement

Not allowed:
- Feature expansion driven by hype
- Market-chasing additions
- Visibility optimization for growth metrics
- Reactionary construction

Repair preserves coherence.
Reaction dissolves it.

Stillness precedes expansion.
Integrity precedes visibility.
