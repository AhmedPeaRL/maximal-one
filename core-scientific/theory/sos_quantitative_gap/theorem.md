# Theorem: Quantitative Lower Bound on Minimal SOS Degree

Let K ⊂ ℝ^m be compact and Archimedean.

Let {p_n} be a structured polynomial family of degree bounded independently of n, constructed as:

p_n(x) = q(x) + ε_n r_n(x),

where:

- q(x) > 0 on K,
- r_n generates a moment-separating dual certificate,
- ε_n chosen such that spectral separation persists.

Define minimal SOS degree:

d_min(p) := inf { d : p ∈ Σ_d }

where Σ_d denotes the cone of SOS polynomials of degree ≤ d.

Then there exists C > 0 such that:

d_min(p_n) ≥ C · g(n),

where g(n) is explicitly computable from the dual moment growth rate.
