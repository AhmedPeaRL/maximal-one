# Assumptions

A1. K is compact and satisfies the Archimedean condition.

A2. Moment matrices M_d(y) are well-defined up to degree D.

A3. Dual feasibility holds:
     y ∈ M_d^*  and  M_d(y) ⪰ 0

A4. Spectral gap condition:
     λ_min(M_d(y_n)) ≤ −γ(n)

A5. Perturbation ε_n sufficiently small:
     ε_n < c / ||r_n||

These ensure separation persists.
