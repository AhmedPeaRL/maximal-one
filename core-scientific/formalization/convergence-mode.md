# Mode of Convergence

Let α_n be bootstrap estimates.

We define convergence in probability:

α_n → 0.5  in probability

iff:

For all ε > 0:

P(|α_n - 0.5| > ε) → 0  as n → ∞

This replaces heuristic thresholding with asymptotic definition.

Finite-sample CI enforces statistical proximity via z-score.
