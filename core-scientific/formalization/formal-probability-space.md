# Formal Probability Space Definition

## 1. Sample Space (Ω)

Let Ω be the space of all finite bootstrap-resampled spectral trajectories
generated from the deterministic kernel K under fixed seed s.

Ω = { T_i : T_i = Bootstrap(K, s, n) }

where:
- K is the deterministic kernel
- s is fixed seed
- n is sample size
- T_i is a bootstrap trajectory

## 2. Sigma Algebra (𝓕)

𝓕 is generated by cylinder sets over finite-dimensional projections
of spectral exponent estimators α.

## 3. Probability Measure (P)

P is induced by the bootstrap resampling mechanism
under fixed seed s.

This ensures:
- Deterministic reproducibility
- Measurable event structure
- Explicit probabilistic interpretation

## 4. Random Operator Definition

Define operator:

R : Ω → ℝ

R(T_i) = α_i

where α_i is the estimated spectral exponent.

R is measurable with respect to (Ω, 𝓕, P).
