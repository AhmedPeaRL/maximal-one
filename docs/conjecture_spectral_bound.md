# Conjecture: Finite-Length Spectral Bound for Linear Recurrence PRNGs

## Setting

Let {X_j}_{j=0}^{N-1} be a finite slice of length N
generated by a linear recurrence PRNG (e.g., MT19937),
mapped to real values in [0,1).

Define the normalized discrete Fourier transform:

F_k = (1/N) * sum_{j=0}^{N-1} X_j * exp(-2π i j k / N)

Define the spectral deviation functional:

S_N = max_{1 ≤ k ≤ N-1} |F_k - E[F_k]|

## Conjecture

There exists a constant C > 0 such that
for all seeds and all N ≥ N0:

S_N ≤ C * N^{-α}

for some α > 1/2.

## Motivation

For independent uniform variables,
concentration suggests α ≈ 1/2 (up to log factors).

If a linear recurrence PRNG satisfies α > 1/2,
this indicates structurally stronger spectral flattening
induced by its transition matrix.
