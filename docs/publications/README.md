# HCM Publications

This directory provides the publication index for the
Hybrid Consciousness Model (HCM) research record.

The authoritative publication records are hosted by Zenodo.
This repository provides persistent discovery links,
manuscript-source references, and provenance information.

## Publication identity

Each publication entry must distinguish:

- Version-specific DOI: identifies one exact published version.
- Concept DOI: identifies the work across its versions.
- Repository manuscript: an editable source representation.
- Published PDF: the exact file deposited in Zenodo.

A repository manuscript must not be described as byte-identical
to a published PDF unless binary identity has been verified.

## Identity and provenance

The publication registry is:

`HCM_ZENODO_PUBLICATIONS.csv`

It records the DOI pair, title, publication metadata,
file identity fields, manuscript path, and verification status.

A binary identity claim requires:

1. Downloading the exact published file from its Zenodo record.
2. Checking the published filename and byte size.
3. Comparing the downloaded MD5 with the Zenodo record metadata.
4. Computing and recording SHA-256 for the downloaded bytes.
5. Recording the retrieval date and verification method.

A mismatch must remain visible until reconciled.
No historical metadata may be silently overwritten.

## Relationship to the computational repository

These conceptual publications document the HCM research
framework and its conceptual development.

They do not, by themselves, establish the empirical validity
of the repository's computational hypothesis.

The computational research status remains governed by
the repository's scientific validation protocols,
independent review requirements, and falsification gates.

Publication existence, computational reproducibility,
scientific validity, and independent replication
are separate claims.

## Authorship and publication metadata

Published authorship and licensing metadata must be
reproduced exactly as stated in the corresponding
Zenodo record.

Repository contributions and manuscript provenance
must not be used to silently alter published authorship.
