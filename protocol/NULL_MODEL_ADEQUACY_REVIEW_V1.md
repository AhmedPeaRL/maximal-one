4. Amendment control

Any model-family, order-range, fitting, calibration, or threshold change made after reviewing existing endpoint results must be recorded as an exploratory amendment.

The amendment record must include:

- Previous protocol and exact commit
- Proposed change and scientific rationale
- Evidence motivating the change
- Potential effects on false-positive rate and endpoint distribution
- Tests and diagnostics to be performed
- Confirmation that the existing endpoint result did not select the change
- New validation requirements

Do not treat the same data used to motivate a change as independent confirmatory validation of that change.
