# Localized Positivity Conjecture

Let p(x)/q(x) be a rational function on ℝⁿ
such that:

1. q(x) > 0 for all x in domain D
2. p(x)/q(x) > 0 on D

Define embedding:

    z = 1/q(x)

and algebraic constraint:

    z q(x) = 1

Conjecture:

Positivity of p(x)/q(x) on D
is equivalent to positivity of

    p(x) z

on the algebraic variety:

    { (x,z) | z q(x) = 1 }

Moreover, if the embedded set is compact,
then polynomial positivity can be certified
via SOS on the lifted space.

This conjecture defines a localized
non-Archimedean quadratic module framework.
