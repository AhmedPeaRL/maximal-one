# Security Policy

## Project and Support Status

This repository is research software and does not currently publish a
versioned security-support matrix.

The `main` branch is the public development line.

The `review/type1-v4-remediation` branch is a development and review
branch. It is not a supported release.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues,
discussions, commits, or pull requests.

Use GitHub's private vulnerability reporting feature for this
repository when it is available.

If private vulnerability reporting is unavailable, contact the
repository owner through GitHub and request a private reporting
channel before sharing technical details.

A useful report should include:

- The affected commit SHA.
- The affected file or workflow path.
- Reproduction steps.
- The potential impact.
- A suggested mitigation, if known.

Do not include real credentials, access tokens, passwords, personal
data, or live exploit payloads in a report.

## Response Expectations

There is currently no guaranteed response-time or remediation SLA.
Reports will be acknowledged and assessed according to availability
and severity.

## Disclosure

Please allow the repository owner a reasonable opportunity to
investigate and address a confirmed issue before public disclosure.
